# ResourceList

A titled list of downloadable publications, each a link with a file-extension icon and the type and size in brackets.

**Markup**: `.content-element__content.content-element__content-resource.content-element__content--wide-links` with an `h2.content-element__title.h4` and one `p > a` per file: the `icon--file-extension` icon, the title, and `span.fileExt` “(PDF, 577 KB)”.

**Rules**: always give the format and size. Offer translated or accessible versions next to the English file, not on another page.
