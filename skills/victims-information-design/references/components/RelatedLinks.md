# RelatedLinks

“Related links and resources”: a short list of documents and pages as bordered link rows with a type badge at the right.

**Markup**: `.block-related > .block-related__inner > .block-related__resources` with an `h3.h5` and `ul.block-related__related-resources` of `a.featured-link`. Rows are `surface` with a `line` border and `radius-md`. A coloured square on the right shows the type: `teal-dark` for internal pages, `teal-bright` for files (`--file-pdf`, `--file-doc` and so on), `blue-external` for external links.

**The consumer provides** the link text with the file type and size in brackets for documents (“When someone dies suddenly (PDF)”).
