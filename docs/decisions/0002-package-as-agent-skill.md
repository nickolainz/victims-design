# 0002 — Package the design system as an Agent Skill

Status: accepted

Date: 2026-10-08

## Context

The Victims Information design system lived in a claude.ai design-system artifact. It needed to be usable from any LLM tool (Claude Code, Claude apps, Codex, and tools without skill support) and kept under version control.

## Decision

- Keep it as one folder, `skills/victims-information-design/`, in the open Agent Skills layout: `SKILL.md` with YAML frontmatter, then `references/`, `assets/` and `scripts/` loaded on demand.
- `SKILL.md` carries a self-sufficient summary of the rules, so a model that can read only that file still stays on-brand.
- `assets/tokens/tokens.json` is the single source of truth; `tokens.css` is generated by `scripts/build_tokens_css.py` and checked by `scripts/verify.py`.
- Component previews are made standalone (relative links to tokens and stylesheet) so they open in any browser.
- The live site remains the design master; the skill follows it.

## Consequences

- The folder can be copied or symlinked into any tool's skills directory.
- Re-syncing from the source artifact is a manual mapping, documented in `references/source.md`.
- Fonts and images are committed directly; the repository is about 6 MB.
